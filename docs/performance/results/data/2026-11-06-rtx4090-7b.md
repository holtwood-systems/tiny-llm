# 7B 模型扩展性 · Qwen2.5-7B Q4_K_M on RTX 4090（2026-11-06）

首个 7B 级门禁外模型实测（此前模型证据最大 0.5B）。

## 配置

- 模型：`/data/models/qwen2.5-7b-instruct-q4_k_m.gguf`
  （sha256 `65b8fcd92af6b4fefa935c625d1ac27ea29dcb6ee14589c55a8f115ceaaa1423`，4.47GB）
- commit `9afe0c0`+；CUDA 12.8.61 / driver 550.107.02 / sm_89
- 干扰：外部租户进程占 ~3.5GiB 显存（见当日记录），结果仍收錄但注意背景
- `tiny_llm_bench <model> --max-tokens 128 --warmup 2 --iters 8 --json`

## 结果（graphs 开启）

| 指标 | 7B Q4_K_M | 0.5B Q4_K_M（同日基线） |
|---|---|---|
| TTFT p50 | 347.1 ms | ~2.8 ms（prompt 长度不同，不可比） |
| TPOT mean | **11.26 ms** | 2.27 ms |
| decode | **88.8 tok/s** | ~441 tok/s |
| RSS 增量 | 22,986 MB | ~3.4 GB |

GGUF 解析、W8A16 kernel 路径、CUDA Graphs decode 在 7B/28层/GQA
配置下开箱可用，无代码改动。

## CUDA Graphs 收益随模型尺寸反比（与 0.5B 对照）

| | graphs | no-graphs | Graphs 收益 |
|---|---|---|---|
| 0.5B TPOT | 2.267 ms | 2.529 ms | **~11%** |
| 7B TPOT | 11.26 ms | 11.53 ms | **~2.4%** |

模型越大每 token 的 kernel 执行时间越长、launch overhead 占比越低，
Graphs 收益递减——符合 launch-bound → kernel-bound 的直觉，实测量化。

有效带宽粗算：Q4_K_M 权重 ~4.4GB / TPOT 11.26ms ≈ **390GB/s**
（RTX 4090 标称 ~1008GB/s，Q4 反量化+GEMV 路径达成 ~39% 峰值带宽）。
