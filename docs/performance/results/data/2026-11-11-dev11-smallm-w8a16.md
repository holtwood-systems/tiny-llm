# DEV-11 小 M W8A16 测量与实现记录（RTX 5070 Ti / sm_120）

数据文件：`2026-11-11-dev11-smallm-w8a16.csv`（`tiny_llm_kernel_bench --smallm`，
warmup=20 iters=200，随机输入；verify 列为独立 CPU float 参考差分）。

## 口径

- 硬件：RTX 5070 Ti 16GB（sm_120），driver 616.56，CUDA 13.3；不与 4090 数据混比。
- `M=1xB`：基线——B 次 M=1 转置快路径调用（生产现状等价物）。
- `M=B`：单次 `w8a16_matmul` 批量调用，走本提交新增的
  `w8a16_matmul_smallm_transposed_kernel<MVAL>`（M∈{2,4,8} 模板实例）。

## 结论（kernel 层，非端到端）

- 旧 dispatch（reference/tiled）在 M∈{2,4,8} 全部劣于 B×M=1，最大
  M=2/K=896/N=4864 慢 16.7×——瓶颈实测成立。
- 新 small-M kernel 相对 B×M=1 提速 1.7–6.3×（M=8/K=896/N=896 达 6.2×），
  相对旧路由最高 ~27×；权重读取被 M 行摊薄是主收益。
- 全部形状通过独立 CPU 参考校验（fp16 累加容差内）；memcheck 0 errors、
  racecheck 0 hazards。
- 非 {2,4,8} 的 M 与缺转置缓冲的调用交回既有路由，行为不变。
- 边界声明：kernel 级提速不等于端到端 serving 提速（attention/KV scatter
  仍逐序列）；端到端 A/B 属 DEV-13 范围。

## 验证

- `tiny_llm_tests`：256 passed / 11 env-skipped（模型路径未设），0 failed；
  新增 4 项 SmallM 测试含真实形状、N/K 尾、组边界、零输入、非模板 M 回退。
- `compute-sanitizer memcheck/racecheck`（SmallM 套件）：0 errors / 0 hazards。
